# Owl Standard — 事實核查規範

**點解要有呢份嘢：** 社交帖會講法定日期、罰款金額、費用階梯。呢啲一錯，就直接違反
`company.md` 嘅合規紅線。網上關於簡樸房嘅資訊好多都係二手轉述、媒體簡化版、或者已經過期，
所以「搵到有講」唔等於「可以引用」。

呢份規範照搬 owlstandard.com 網站自己嘅做法（見網站 repo `CONTEXT.md` 嘅 Citation 一節）——
嗰邊已經行緊呢套，兩邊用同一套標準先唔會自打嘴巴。

---

## 一、官方來源白名單（只可以信呢啲）

任何法規事實，**只接受**以下來源。唔喺呢個名單入面嘅，一律當「未經核實」：

| 用途 | 網址 |
|---|---|
| 條例正式文本（最高權威） | `elegislation.gov.hk/hk/cap658` |
| 房屋局簡樸房專頁（制度、表格、指引） | `bhu.gov.hk/tc/regulatory-regime/*` |
| 屋宇署（**只限**建築工程／法定命令，唔係認證） | `bd.gov.hk/*` |
| 差餉物業估價署（租務相關） | `rvd.gov.hk/*` |
| 政府新聞公報（政策公布、日期變更） | `info.gov.hk/gia/general/*` |

**硬規則：**
- 唔准自己砌網址。搵唔到就報「搵唔到」，唔好估一條似樣嘅出嚟。
  （呢個係 YMYL 內容——**虛構來源比冇來源更差**。）
- 傳媒報道（星島、HK01、明報等）**只可以做線索**，唔可以做引用來源。
  睇完之後一定要返上面嘅官方來源核實返。
- 同行／競爭對手網站、律師行 blog、討論區：**一律唔可以做來源**。

## 二、遇到衝突點算

**條例原文永遠贏。** 如果房屋局摘要同條例附表講法唔同，以 `elegislation.gov.hk` 嘅條文為準。

呢件事真係發生過：`ordinance-cap658.md` §十 情況(b) 嘅日期本身自相矛盾（同一段時間又話 $0
又話 $1,500），係對照政府新聞公報原文先改正到。所以**唔好見到一個數字就照抄，要睇埋前後有冇打架**。

## 三、要定期覆核嘅項目（呢啲會變）

| 項目 | 現時值 | 點解要覆核 |
|---|---|---|
| 執法日 | 2027-03-01 | **條例第1(4)條寫明局長可以憲報公告押後。** 呢個係最高風險項目 |
| 寬限期登記截止 | 2027-02-28 | 同上，會隨執法日一齊郁 |
| 全面執法 | 2030-03-01 | 同上 |
| 認證費階梯 | $0 / $1,500 / $3,000 | 附表2 可以修訂 |
| 續期費 | $2,400 | 同上 |
| 罰則 | $300,000 + 3年，每日另罰 $20,000 | 第8(3)條 |
| 全港登記進度 | （未追蹤） | 房屋局按週更新名冊，係好內容素材 |

**覆核頻率：** 每季一次，或者見到傳媒報道有政策變動就即刻做。

**覆核之後要改邊度：**
- `companies/owl-standard/company.md`（合規紅線嗰段）
- `companies/owl-standard/topics.md`（lens 描述入面嘅數字）
- `scripts/write-caption.mjs` 同 `scripts/derive-concept.mjs` 嘅 `BANNED` 規則
  （例如「60個月」呢類寫死咗嘅字眼）

## 四、點樣叫 AI 做呢件事

畀 Claude Code（或者任何 agent）嘅指令模板：

```
覆核簡樸房條例（Cap. 658）以下項目有冇變更：執法日、寬限期登記截止日、
認證費階梯、續期費、罰則金額。

只接受 companies/owl-standard/fact-check.md 白名單內嘅來源。
逐項報：現時值 / 查到嘅值 / 來源網址 / 有冇變。
搵唔到就寫「搵唔到」，唔好估。
```

**唔好接受冇附網址嘅答案。** 每個數字都要指到白名單入面一條實際網址，你要抽查得到。

## 五、最後一道關係人手

呢份規範降低出錯機會，但唔消除。每篇帖出街前你都會喺 Telegram 睇一次——
**見到具體日期或者金額，就當場對一次上面嗰張表**。呢個係最後亦最可靠嗰道關。
