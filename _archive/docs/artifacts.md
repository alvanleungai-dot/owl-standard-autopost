# Artifacts registry — social-content-engine

Shareable visual explainers for this project. **Source of truth = the HTML in `docs/artifacts/`**; the
"Live URL" is a published, default-private claude.ai view of that source.

**How to update one (so the shared link stays the same):** edit the source file below, then re-publish the
Artifact passing that row's **Live URL** (the `url:` param). Do **not** publish from a new file path — that
mints a new URL. Artifacts do **not** auto-update; regenerate when the plan changes.
